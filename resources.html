Resources

Books · the software you will need · materials outside the course

The main books

James, Witten, Hastie, Tibshirani and Taylor (2023). An Introduction to Statistical Learning with Applications in Python. Springer.

The principal textbook of this course. The publishers make the complete book available at no cost at statlearning.com.

Géron (2025). Hands-On Machine Learning with Scikit-Learn and PyTorch. O’Reilly.

The practical companion to the theory. Its notebooks and appendices are at homl.info.

Bishop and Bishop (2024). Deep Learning: Foundations and Concepts. Springer.

A modern introduction to deep learning, for anyone who wants to go further than Module 8 does.

Raschka, Liu and Mirjalili (2022). Machine Learning with PyTorch and Scikit-Learn. Packt.

Useful alongside the module on neural networks.

Murphy (2022). Probabilistic Machine Learning: An Introduction. MIT Press.

The same material seen from a probabilistic angle. Freely available at probml.github.io.

The classic references

Bishop (2006). Pattern Recognition and Machine Learning. Springer.

A classic, and mathematically deeper than anything this course requires.

Hastie, Tibshirani and Friedman (2009). The Elements of Statistical Learning, second edition. Springer.

The standard reference for the statistical foundations. Freely available from the authors.

Shorter material

Raschka (2024). Machine Learning Q and AI. No Starch Press.

Short chapters, each answering one question. Freely readable online.

The scikit-learn user guide

The current documentation for the library used throughout the course.

The PyTorch documentation and tutorials

For the neural-network module and for Homework 6.

The software you will need

  • Python, version 3.10 or later, with Jupyter, either on your own machine or in Google Colab.
  • The libraries, installed with pip install numpy pandas matplotlib scikit-learn torch. An ordinary processor is enough; no graphics card is required.
  • Visual Studio Code or JupyterLab, if you prefer an editor to the plain notebook interface. Neither is required.
  • Every notebook in this course runs on an ordinary laptop processor.
