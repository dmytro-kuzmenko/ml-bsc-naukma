Gradient descent and the learning rate

Gradient descent is minimizing the quadratic loss f(x, y) = (x−1)² + 2(y+1)² + 0.6(x−1)(y+1), whose minimum lies at (1, −1). The learning-rate slider moves on a logarithmic scale. The contours in the background are the loss surface, and the dark path is the route that gradient descent takes from its fixed starting point at (3.0, −3.2).

Things worth trying

  1. Set the learning rate to 0.001, at the far left of the slider. Running to the end takes 500 steps and still does not arrive at the minimum: a step that is too small simply makes progress too slow.
  2. Set it to the default of 0.1. The descent converges in about 54 steps. This is the stable regime.
  3. Set it to 0.4. The path now swings from one side of the valley to the other before it settles. This is still stable, but it is close to the limit.
  4. Set it to 0.6, and then to 1.0. Each step overshoots, the loss grows without bound, and the trajectory leaves the plot within a few steps. This is divergence.
  5. Return to 0.1 and take the steps one at a time, watching the norm of the gradient. It shrinks as the current point approaches the minimum, which is why the later steps are shorter than the earlier ones even though the learning rate never changes.

One caveat. This demonstration computes the gradient exactly, over the whole dataset at once. When training uses minibatches, the gradient is estimated from a small subset of the data, so the path jitters around the minimum instead of stopping cleanly. The intuition about the learning rate carries over unchanged; there is simply noise on top of it.
